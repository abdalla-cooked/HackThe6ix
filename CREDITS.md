## Art

The current build draws monsters, the mage and file icons with system emoji, so no third-party art files ship yet. When you add art through `js/assets.js`, list each file here:

- Monsters and mage: Kenney Tiny Dungeon | kenney.nl | Kenney | CC0 1.0 | https://kenney.nl/assets/tiny-dungeon
- File icons: game-icons.net | game-icons.net | (each icon's author, e.g. Lorc or Delapouite) | CC BY 3.0 | https://game-icons.net

CC BY 3.0 requires crediting each icon's author by name, so add one line per icon you use.
